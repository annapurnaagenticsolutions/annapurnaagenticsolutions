# What-If Machine v1.3 — Stable Showcase Build

A mobile-first, offline-friendly silly imagination engine that turns impossible questions into funny explanations, tiny comics, character voices, fake reports, poster briefs, share cards, classroom sparks, and recurring absurd worlds.

## What v1.3 changes

v1.3 is a curation and closure build, not a feature-sprawl build.

- 111 prompt packs / 1344 curated prompts.
- Best 100 showcase prompt layer in `data/best-100-showcase.json`.
- 8 recurring absurd characters in `data/recurring-characters.json`.
- Share-card template bank in `data/share-card-templates.json`.
- Human-tuned Hinglish sample lines in `data/hinglish-sample-lines.json`.
- Final demo script in `data/final-demo-script.json`.
- Fixed recurring character names that were previously referenced by some outputs but not consistently populated.
- Added Science flavor and Hinglish Showcase language mode.
