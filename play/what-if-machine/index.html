Content boundaries

The machine is designed for harmless absurdity: objects, animals, school routines, weather, food, cities, gadgets, family-safe fantasy, and fake science. Risky prompts are redirected into safe nonsense.

Recommended next direction

After v1.3, treat this track as stable. The next useful work is external: run a small user demo, collect which cards people actually share, and only then decide whether to build a real AI/API version or APK wrapper.
