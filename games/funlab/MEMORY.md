# FunLab Browser v0.6 — Durable Decisions

- Depth still outranks game count.
- A visible action must change actual game state, not only animation.
- Arena combat now separates **opening odds** from **live player intervention**; live health determines the final winner.
- Jugaad's tool *position* is part of the rules. Mobile must preserve the same 6×3 logical grid.
- Adventure ambience may move, but reduced-motion keeps actors static and preserves navigation.
- Fusion history is a play surface, not merely a log: lineage nodes can be reused as reactor inputs.
- Rich rendering remains optional. None of the v0.6 upgrades require a backend or model call to own canonical game state.
- Real-device visual QA remains an external release gate.
