# v0.6 Interaction-Polish Rules

1. **Timing must matter:** a combat button is enabled only when its action is contextually useful and its cooldown is ready.
2. **Position must matter:** Jugaad evaluates cluster, spread and alignment; moving tools can change the same inventory's result.
3. **The world must resist:** adventure maps contain blocking geometry instead of being empty click fields.
4. **Ambient motion is bounded:** one small actor follows a deterministic route and stops entirely under reduced motion.
5. **History becomes interaction:** Fusion ancestry is clickable and feeds discoveries back into the reactor.
6. **Fallbacks preserve the loop:** no v0.6 mechanic depends on WebGL, an LLM, an account or a server.
