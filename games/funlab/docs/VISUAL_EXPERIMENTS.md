# v0.3 Visual Experiments

## Why these three
- **Odd Signal** asks whether visual recognition can produce a sub-30-second replay loop without AI.
- **Orbit Panic** asks whether a small amount of real 3D materially improves tension and spatial legibility.
- **Pocket Garden** asks whether an open-ended system can create timepass through emergence rather than scores or generated text.

## Three.js policy
Orbit Panic uses a runtime import of `https://cdnjs.cloudflare.com/ajax/libs/three.js/0.180.0/three.module.min.js`. The library is MIT licensed. FunLab does not require the import for startup and does not redistribute the module in this package. If loading fails, a local Canvas2D renderer implements the same core survival mechanic.

## Promotion criteria
Do not add 3D to other activities merely because Orbit Panic has it. Promote a richer renderer only when it improves at least one of: spatial comprehension, direct manipulation, spectacle worth sharing, or replay value at an acceptable frame/load budget.
