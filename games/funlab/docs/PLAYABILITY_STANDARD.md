# Browser Fun Playability Standard

A game qualifies as "playable-first" when:
1. Its dominant verb is physical/visual: move, place, drag, tap, aim, time, build, dodge, collect, combine or explore.
2. First meaningful feedback arrives without requiring a paragraph of text input.
3. The world visibly changes after the player's action.
4. Replay changes state, timing, route or consequence—not only the wording.
5. Touch and keyboard/click paths both work where relevant.
6. Reduced motion preserves the game loop, not only the content.
7. Rich rendering is optional and disposable through the shared cleanup lifecycle.
