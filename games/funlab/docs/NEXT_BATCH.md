# v0.7 Candidate — Replay Systems

1. Real-device visual QA and compact Android tuning remains the first external release gate.
2. Add short **skill missions** to the four deepest games: e.g. win with one live counter, solve Jugaad under a placement constraint, reach a clue without touching an obstacle, create a lineage depth of four.
3. Add deterministic **difficulty profiles** that alter timing windows, map obstacle density and spatial constraints without hiding accessibility controls.
4. Give Orbit Panic the same richer replay structure: short objectives, arena variants and meaningful run modifiers.
5. Turn Pocket Garden into a goal-optional ecology playground with visible ecosystem events rather than adding another title.
6. Consider a lightweight local tournament/session playlist across 3–5 activities; no backend required.
7. Keep backend frozen unless persistent shared state becomes genuinely necessary.
