# FunLab Browser v0.6 — Structure

```text
Browser shell
  ├─ Home / daily / local insights
  ├─ Settings + quality/accessibility
  ├─ Local persistence v6
  ├─ Mechanic progression from v0.5
  ├─ Shared play systems
  │    ├─ battle plan + contextual cooldown actions
  │    ├─ Jugaad scenario + spatial-layout scoring
  │    ├─ themed adventure maps / actors / contextual hotspots
  │    ├─ fusion lineage layout
  │    └─ existing orbit / visual helpers
  └─ Game modules
       ├─ Who Would Win → telegraph → action window → exchange → cooldown
       ├─ Jugaad → arm tool → place on grid → choose strategy → simulate
       ├─ What Happens Next → navigate map → avoid obstacles → clue → carry item
       ├─ Fusion Lab → combine → add edge → navigate lineage → recombine
       └─ existing seven activities
```

The intelligence server remains optional and unchanged. Deterministic browser systems own combat health, cooldowns, spatial scoring, adventure navigation and lineage state.
