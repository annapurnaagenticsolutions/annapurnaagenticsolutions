# FunLab Browser v0.6 — Plan

## Goal
Interaction polish: make successful v0.5 systems depend on **timing, position, navigation and accumulated visual history**, rather than adding more activities.

## Implemented batch
1. Telegraph + cooldown combat for Who Would Win.
2. Position-sensitive 6×3 Jugaad construction bench.
3. Scene-specific adventure maps with obstacles, contextual hotspots and moving actors.
4. Clickable branching Fusion lineage map.
5. Storage/cache version migration to v0.6.
6. No backend changes.

## Explicit non-goals
No accounts, cloud persistence, realtime multiplayer, public leaderboard, payment, mandatory model calls, new game-count expansion, native wrapper or backend modification.
