How this hub works

Keep the hub light. Keep each experience focused.

1

Bookmark WonderHub

Users return here as the front door for all current and future learning websites.

2

Select an interest

Study, play, color, read, build, or explore future skills from a single organized index.

3

Open the dedicated site

The actual lessons, activities, games, and stories remain inside their own specialized websites.

Built for growth

Add a future website by editing data/sites.json.

This keeps WonderHub maintainable. Every new initiative only needs a title, category, short pitch, status, tags, and URL. 

{
  "title": "Animal & Dinosaur World",
  "category": "Stories",
  "ageRange": "Class 1–5",
  "status": "Coming Soon",
  "url": "#",
  "description": "A child-friendly gateway for animal facts, dinosaur stories, and nature learning.",
  "tags": ["Animals", "Dinosaurs", "Nature"]
}
