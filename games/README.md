# Annapurna Play & Learning Worlds

This directory is the source-controlled staging area for the browser experiences that will eventually be published through the Annapurna play platform.

## Staged projects

| Directory | Public identity | Initial role | Notes |
| --- | --- | --- | --- |
| `wonderhub/` | WonderHub | Learning-world catalogue | Discovery hub; not a standalone game |
| `funlab/` | FunLab | First platform launch candidate | Eleven browser-first activities with a release-gate process |
| `oneiric/` | ONEIRIC | Standalone game | Current evolution of the earlier Lantern Warden concept |
| `vidya-yantra/` | Vidya Yantra | Learning-world showcase | Babylon/React application; backend and chapter coverage still require validation |
| `varsha-hollow/` | Varsha Hollow | Narrative-world showcase | Complete authored chapter set; completion and deployment checks remain |

Lantern Warden is retained as a product-history label for the earlier roguelite iteration. It is not copied as a duplicate codebase because the current source evolved into ONEIRIC.

Generated dependencies and build output are intentionally excluded. Each project should be built in its own deployment pipeline.
