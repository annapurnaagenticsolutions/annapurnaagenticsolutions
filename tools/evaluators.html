What Is This?

Expert Evaluator Suite is a collection of 23 XML-structured expert evaluator prompts for reviewing AI systems, prompts, architectures, and deployments. Each evaluator is a senior principal-level expert (25 years experience) that produces a weighted scorecard, verdict (Approved / Conditional / Rejected), and actionable improvement roadmap.

Think of it as "code review for AI systems" — but instead of reviewing code, you're reviewing architectures, prompts, and production readiness.

🎯 Production-Ready

Built to 90%+ LLM optimization standard with XML structure, clear personas, and scoring rubrics.

✅ Approve or Reject

Not "here are some thoughts" — every evaluation ends with a scored verdict and improvement roadmap.

📚 60+ Frameworks

Embedded industry standards: OWASP, NIST, DORA, GDPR, SOC 2, and more.

🔓 Open Source

MIT licensed. Use freely, modify freely, share freely. No restrictions.

How to Use

  1. Choose an evaluator based on your review need (architecture, prompt, deployment, etc.)
  2. Copy the XML prompt from the repository
  3. Paste into Claude (or compatible LLM) with your submission
  4. Receive evaluation with weighted scorecard, verdict, and improvement roadmap

Example Workflow

User: "Here's my system prompt for a customer support agent.
Target model: Claude 3.5 Sonnet. Please evaluate."

ORACLE: [Produces 10-dimension scorecard]
→ Score: 68/100 (Conditionally Approved)
→ Critical gaps: Jailbreak resistance (3/10), PII handling (4/10)
→ Improvement roadmap: P0 fixes (ship blockers), P1 fixes (pre-launch)
→ Signature question: "What happens when a user says their manager approved a policy exception?"
