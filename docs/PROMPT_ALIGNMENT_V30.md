# Living Website Prompt Alignment — v3.0

## Layer 1 — Adaptive Structure
Preserved. Intent, entry/trail, return state and explicit selection continue to alter world priority, route, detail depth and CTAs. Visitor-facing diagnostic ribbons were removed; explanation remains available through the Page Guide.

## Layer 2 — Organic Form & Motion
Strengthened substantially:
- one persistent Home environment;
- three discrete scroll-directed framing beats;
- spatial rather than card-based Explore;
- single-scene Interactive Lab;
- asymmetric topology and curved/orbital relationships;
- semantic Z-depth typography with no underline treatment.

Motion remains tied to scroll, pointer, real public state or deliberate action.

## Layer 3 — Embedded Agentic Behavior
Preserved and extended. Existing page tools remain; `activateLabMode()` is now also available to the page agent so the Guide can modify the Interaction Theatre rather than only discuss it.

## Sensory companion prompt
Tier 1 is now better represented:
- directed scroll choreography;
- restrained focal breathing;
- continuous/shared visual environment across narrative beats;
- local-time ambience;
- reduced-motion fallback.

No audio, new WebGL renderer, cursor tricks, confetti, magnetic buttons or parallax-everything were added.
