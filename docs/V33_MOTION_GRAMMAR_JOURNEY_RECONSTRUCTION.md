# v3.3 — Motion Grammar + Journey Reconstruction

## Objective
Repair the remaining Home continuity failure and make the existing material layer easier to perceive without adding a new feature family.

## Journey reconstruction
The Home story now uses an explicit two-area grid: `story | world`. The copy stack defines the complete story height, while the world rail stretches through that same grid row and contains one sticky ecosystem. The story shell no longer clips the sticky lifecycle on desktop.

The same ecosystem must therefore survive:
1. Establish
2. Focus
3. Journey

Journey reveals the existing route overlay *inside* the persistent stage. It does not replace the environment.

## Annapurna motion grammar
Every major physical response uses the same causal rhythm:

`Sense → Anticipate → Transform → Propagate → Settle`

- **Sense**: deliberate world/input/scroll state is identified.
- **Anticipate**: the focal object compresses/lifts briefly.
- **Transform**: geometry/material reorganizes.
- **Propagate**: related worlds or downstream elements visibly receive the change.
- **Settle**: the environment returns to a stable readable state.

The sequence is short enough to preserve usability and is never an autonomous spectacle loop.

## Material visibility
The Canvas2D bridge remains lightweight, but deliberate interactions now use more visible particles, short particle trails and a clearer formation/settling phase. The effect still disappears under reduced motion and on narrow mobile layouts.

## Inner pages
- Explore: selection changes orbital geometry and propagates emphasis to connected worlds.
- Lab: Runtime faults physically fracture/reroute the path; AXON presets reshape the workflow topology while retaining the single-theatre design.
- CTA: a temporary arrival signal visually continues the Journey into the next action.

## Boundaries
No new page, panel, relationship, analytics mechanism, external runtime, framework or WebGL context is introduced.
