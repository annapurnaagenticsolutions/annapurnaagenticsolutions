# Prompt Synthesis — v1.8

## Master prompt adoption
### Adaptive Structure
Retained from v1.4+: explicit intent, referrer/entry context, recent deliberate exploration and return state feed a deterministic decision layer. The decision changes section order, detail depth, primary world, product order, Interactive Lab order and CTA paths.

### Organic Form & Motion
Strengthened in v1.8: white-first spatial stage, six world-specific scene grammars, pointer-linked depth, scroll-linked depth, subtle focal breathing, shared-element page transitions and mobile swipe.

### Embedded Agentic Layer
Retained and simplified for visitors: Annapurna Guide can focus the page, navigate, highlight products, change detail depth, explain the current route and follow product connections.

### Live/Temporal Data
Repository signals animate when the static generated data changes. Shared interval state and visitor-local daypart ambience remain separate.

## Sensory prompt adoption
### Tier 1 — adopted
- scroll-driven scene choreography;
- subtle idle breathing on the central focal element;
- narrative-aware page transitions;
- client-side local-time ambience.

### Tier 2 — deferred
- ambient shader backgrounds;
- ambient audio.

### Explicitly skipped
Cursor trails, magnetic hover, custom cursor, confetti and parallax-everything.

## New v1.8 interpretation
The sensory layer is allowed to amplify meaning, but it may not become a separate “demo section.” It is woven into the product ecosystem itself.
