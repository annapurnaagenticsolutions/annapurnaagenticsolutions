# v1.3 Interaction Quality Decisions

## Objective
Make the white professional site feel unmistakably alive through **response, causality, memory and connection**, not through constant spectacle.

## Decisions
1. Keep the four-page information architecture unchanged.
2. Give each product world a distinct visual grammar: governed network, learning constellation, MSME city, typed-flow lanes, experience frames, experimental grid.
3. Make world selection causal: node → scene grammar → context → relationship → signal burst.
4. Make the Annapurna core an explicit control that pulses the two connected worlds without changing visitor memory.
5. Add horizontal swipe on touch/pen while preserving normal vertical page scroll.
6. Remember only deliberate world selection/swipe; hover/focus preview remains ephemeral.
7. Separate exploration phase from return-session state.
8. Tighten typography again instead of allowing immersive interaction to drive display sizes upward.
9. Make Lab controls provide immediate state feedback and animated causal transitions.
10. Keep reduced-motion, forced-colors, keyboard navigation and static-first rendering intact.
11. Do not add Three.js/WebGPU until this interaction model has been judged insufficient after deployment/user testing.

## Living test
A feature qualifies as “living” only if it demonstrates at least one of: real response, stateful continuity, causal system change, environmental context, or verifiable external change. Decorative animation alone does not qualify.
