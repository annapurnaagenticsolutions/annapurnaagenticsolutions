# v3.5 — Spatial Coherence + Living Field Intelligence

## Why this release exists
v3.4 repaired Home Journey ownership, but the next screenshot set exposed a second class of spatial failure on Explore: the selected-world inspector could occupy the same visual field as topology, creating the impression that content, graph lines and world nodes were colliding.

## Explore: narrative rail + living field
The selected-world narrative is now a sibling rail outside the spatial atlas. The atlas owns only topology. A lightweight layout governor positions the six world nodes inside safe bounds, avoids the Annapurna core and resolves local node collisions before paint settles. Mobile intentionally stacks the field above the narrative rather than trying to preserve a cramped two-column map.

## Journey: morph, do not duplicate
The route overlay no longer presents a second set of product labels. Route geometry is rebuilt from the actual world-node positions. Existing nodes receive route order/current/past state, while the signal moves between those same nodes. This makes Journey read as a transformation of the established ecosystem.

## Semantic field physics
Explore now carries the same semantic six-world grammar already established on Home: governed network, learning constellation, practical city, typed lanes, experience frames and experimental grid. The active world changes restrained field texture rather than merely changing accent color.

## Boundaries
No new page, framework, third-party runtime, WebGL context, network dependency, product truth, evidence claim or visitor identity model is introduced. v3.4 structural anchors and all inherited truth/accessibility contracts remain authoritative.
