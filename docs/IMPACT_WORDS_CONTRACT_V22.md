# Impact Words Contract — v2.2

Impact typography is allowed only when all of the following hold:

1. The word is semantically important, not decorative filler.
2. Depth responds to user action, active product world, or scroll phase.
3. Maximum depth remains restrained and does not obscure neighboring text.
4. The baseline sentence remains fully readable with CSS/JavaScript disabled.
5. Reduced-motion removes the transform.
6. Low-power mode reduces depth and removes heavy shadow.
7. The effect must not be applied to every heading.

The intended sensation is **foreground depth**, not bouncing text or an advertisement-style jump animation.
