# v1.3 Comprehension / Professionalism Audit

## First-screen questions
1. **What is this company?** AI infrastructure, learning worlds, practical digital tools and interactive experiences are stated in the hero.
2. **What should I do?** Primary action is “Explore the ecosystem”; secondary action is “Open Living Lab.”
3. **Why is this site different?** The live ecosystem is visible beside the positioning statement, with explicit tap/core/swipe cues.
4. **Where is detailed proof?** Evidence is a dedicated primary-navigation destination, not landing-page content.

## Quantitative guardrails
- Home sections: 5 (ceiling 6)
- Primary navigation links: 4 + Contact
- H1: 8 words (ceiling 12)
- Home visible text: ~340 words (ceiling 480)
- Hero display size: ≤54px desktop / 36px mobile
- Inner-page H1: ≤48px
- Main body: 13–17px
- Touch interaction floor: 44px

## Language guardrail
Home must not expose engineering-release vocabulary such as JSON Schema, semantic history, release candidate, telemetry contract or version identifiers.

## Remaining validation
The real release still needs deployed browser/Lighthouse evidence and short external-user comprehension testing. The local sandbox cannot substitute for those tests.
