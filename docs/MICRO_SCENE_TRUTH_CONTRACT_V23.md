# Micro-scene Truth Contract — v2.3

Micro-scenes are interaction models, not claims about real product execution.

They may:
- move visual topology;
- highlight product relationships;
- emit local visual signals;
- change temporary scene copy.

They may not:
- claim live runtime activity;
- persist completion as visitor intent;
- upgrade maturity;
- write public history;
- modify Evidence Atlas claims;
- infer identity or user profile.

Source of truth: `data/living-world-v23.json`.
