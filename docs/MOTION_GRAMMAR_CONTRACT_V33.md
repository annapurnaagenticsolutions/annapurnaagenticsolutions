# Motion Grammar Contract — v3.3

Major visual responses follow five stages: **Sense → Anticipate → Transform → Propagate → Settle**.

## Allowed triggers
- deliberate product-world selection;
- directed Focus/Journey scroll beat;
- Interactive Lab input changes;
- arrival into the final Home CTA.

## Not allowed
- unprompted continuous spectacle;
- movement that changes product truth or evidence;
- stored motion state used as profiling;
- underlined impact typography;
- particle effects that remain active indefinitely.

Reduced-motion removes nonessential transforms and particle animation while preserving content, topology and controls.
