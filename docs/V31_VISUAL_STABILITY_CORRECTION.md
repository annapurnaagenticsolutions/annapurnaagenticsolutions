# v3.1 — Visual / Stability Correction

## Objective
Correct the presentation regressions visible in the first v3.0 screenshots without adding a new living-system feature layer.

## Home corrections
- The Home story grid now stretches the world rail across the complete Establish → Focus → Journey narrative. This gives the sticky ecosystem a valid containing block for the entire story.
- Journey no longer carries the legacy `route-section` class; route-scroll logic targets `#living-response` directly.
- The hero copy column is wider and the maximum headline size is reduced.
- The em dash before **Connected** was removed so it cannot appear as a stray line when the word wraps.
- Impact words remain non-underlined. Depth comes from perspective, restrained shadow and contextual color.
- Journey keeps relevant product worlds readable rather than fading the environment away.
- Software Lab and the stage label receive safer top insets below the sticky header.

## Explore corrections
- The spatial atlas is retained.
- Inactive worlds are less faded; they should read as distant, not disabled.
- Related worlds receive stronger prominence.
- The inspector is slightly smaller and more translucent so the field remains primary.

## Interactive Lab corrections
- The single-theatre architecture is retained.
- Theatre height and internal spacing are reduced to remove unnecessary blank space.
- On desktop, the mode rail is sticky with a header-safe offset.
- On tablet/mobile the rail returns to normal flow.

## Explicitly unchanged
No new product behavior, causal relationship, agent capability, evidence claim, framework, WebGL context or visitor-tracking mechanism was introduced.
