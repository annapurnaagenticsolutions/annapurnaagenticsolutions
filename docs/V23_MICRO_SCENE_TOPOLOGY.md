# v2.3 — Micro-scene Topology

## Objective
Make each world feel like a small living system rather than a node that only changes color or plays an animation.

## Six micro-scenes
- **AI Solutions** — open governed paths; AXON and Website Studio converge toward the policy/evidence/execution core.
- **WonderHub** — connect learning sparks; Website Studio and Idea Hub join a learning constellation.
- **Idea Hub** — grow practical blocks; Software Lab and Website Studio form a delivery corridor.
- **AXON** — route typed packets; AI Solutions, AXON and Software Lab align into lanes.
- **Website Studio** — shape experience frames; WonderHub and AI Solutions become part of the composition.
- **Software Lab** — activate experiment cells; AXON and Idea Hub snap into an experimental grid.

Each micro-scene has three native-button interaction points. The central Annapurna core can advance the same three-step scene.

## Boundaries
Micro-scene progress is ephemeral. It is not stored in local memory, is not evidence, and cannot alter product state or semantic history. Selecting another world interrupts the current micro-scene immediately.

## Mobile/reduced motion
On narrow touch layouts, topology movement of product labels is disabled to avoid overlap; the interactive points and state changes remain. Reduced-motion removes animated transitions while preserving the three-step topology state.
