# Causal Response Contract

The Living Website should make four stages inspectable:

**Sense → Decide → Respond → Explain**

- Sense: explicit intent, entry/referrer, recent local exploration/return state, shared temporal state.
- Decide: deterministic rules-first adaptive model.
- Respond: structure order, detail depth, primary world, CTA and cross-page priority.
- Explain: the Living Response receipt and Page Guide can state why the current view exists.

Motion is permitted only as feedback to a real state change or deliberate visitor action. Reduced-motion removes animation but preserves state changes.
