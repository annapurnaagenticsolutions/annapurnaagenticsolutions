# Cross-world Truth Contract — v2.4

Cross-world consequences are an experiential model of portfolio relationships.

They may:
- leave temporary visual afterglows;
- draw cross-world currents;
- change a target micro-scene cue;
- alter ephemeral topology and motion.

They may not:
- claim that one production product actually invoked another;
- persist across page loads;
- modify product maturity;
- write semantic history;
- modify Evidence Atlas claims;
- infer or store a visitor profile.

Exact relationship targets must match the existing interaction connection graph.
