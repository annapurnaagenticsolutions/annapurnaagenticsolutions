# v1.4 Adaptive Architecture

## Pipeline
`real signal -> deterministic intent decision -> structural composer -> page tools -> static fallback`

## Signal priority
1. Explicit self-selection.
2. Entry context: `?intent=` or known same-origin product referrer.
3. Recent deliberate world trail.
4. Genuine return session / last world.
5. Balanced default.

Hover/focus previews are not adaptive signals. Only deliberate interaction can enter the local trail.

## Structural outputs
An intent can change:
- order of Home's proof / capabilities / living-response blocks;
- order and priority of the three capability families;
- order of the six product worlds on Explore;
- order of the three Living Lab rehearsals;
- concise / standard / deep presentation depth;
- initial ecosystem world;
- primary and secondary CTA routes.

This is deliberately more than headline personalization.

## Safe fallback
All source HTML is complete before JavaScript. Intent controls are hidden until the model is available; the page guide is enhancement-only. A JSON, storage or guide failure leaves the ordinary site available.

## Future model upgrade boundary
`deriveIntent()` can later be replaced by a cached classifier or model without changing the structural composer or page-tool API. v1.4 does not justify an LLM call because five explicit intent classes remain deterministic and inspectable.
