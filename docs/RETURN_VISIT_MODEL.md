# Return-Visit Model v1.3

The website maintains two independent, device-local concepts.

## 1. Exploration phase
Derived only from intentionally selected product worlds:
- Observing — 0 worlds
- Mapping — 1+
- Connecting — 3+
- Constellation — 5+

## 2. Return state
Derived from separated local sessions, not page views:
- First encounter — session 1
- Returning — session 2+
- Familiar — session 4+
- Embedded — session 7+

A new session requires at least **360 minutes of inactivity**. Navigating Home → Explore → Living Lab remains one session.

## Privacy and truth boundary
Stored data is limited to session timestamps/count, explored world IDs, a six-world trail and last selected world. There is no identity, fingerprint, server analytics or behavioral score. Return state affects ambient density and copy only. It cannot modify product maturity, evidence manifests, repository data or semantic public history.

## Migration
v1.2 local exploration/trail state is migrated to `annapurnaLivingV13`, but old page-load “visit” counts are intentionally discarded because they did not represent true return sessions.
