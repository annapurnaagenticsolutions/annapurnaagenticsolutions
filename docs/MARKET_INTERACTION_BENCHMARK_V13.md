# Market Interaction Benchmark — v1.3

Reviewed current immersive-web patterns in August 2026.

## Patterns worth adopting
- Instant interface feedback and microinteractions improve perceived continuity and responsiveness (Awwwards mobile performance guidance).
- Mobile experiences need appropriate tap targets, legible typography and device-specific interaction rather than desktop effects compressed onto a phone (Awwwards Mobile Excellence guidance).
- Lusion’s Worldcoin Globe is a useful reference for real data driving real-time graphics, rather than animation that is disconnected from system state.
- Current high-scoring immersive work such as GQ/AP The Extraordinary Lab shows that scroll/WebGL can achieve very high visual/UX impact, but v1.3 intentionally does not copy that rendering stack before the interaction model is validated.

## Annapurna’s chosen gap
Professional white business surface + meaningful interaction + harmless continuity + inspectable evidence + external public-state signals.
