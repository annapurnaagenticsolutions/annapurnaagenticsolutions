# v2.1 — Environmental Interactivity

## Objective
Deepen v2.0 without adding sections or reverting to dashboard UI. The ecosystem should feel continuously connected, react across acts, and reveal real activity through behavior.

## Changes
1. **Resonance field** — deliberate world selection keeps related worlds prominent and lets unrelated worlds recede.
2. **World wake** — an intentional selection briefly changes atmospheric scale/glow; it is action-linked, not autoplay spectacle.
3. **Real-state current** — `repository-signals.json` influences flow density and packet velocity. Home does not display repository metrics.
4. **Cross-act propagation** — selecting a world recomposes the Connected Journey and final CTA.
5. **Continuity thread** — scroll progress carries a signal from the Living Ecosystem into the journey below.
6. **Tactile core** — pointer position gives the ecosystem core a maximum four-pixel physical response.
7. **Return evolution** — returning/familiar visitors get a denser field based only on device-local session state.
8. **Interruptible automation** — any deliberate world selection overrides a guided path immediately.

## Boundaries
- No new framework.
- No additional WebGL context.
- No analytics or identity tracking.
- Repository activity is engineering evidence, not adoption or product maturity.
- Reduced-motion removes breathing/path animation but preserves the same information and navigation.
