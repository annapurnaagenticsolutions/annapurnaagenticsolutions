# v1.6 — Perceived Liveness & First-Visit Clarity

## Problem found
v1.5 behaved adaptively, but a first-time visitor could miss the causal chain. The site was alive internally before it was obviously alive externally.

## Changes
1. **Living response receipt** exposes the three active inputs: intent, memory/return state and shared temporal state.
2. The receipt shows the actual output: first section, detail depth, primary world and CTA.
3. A first-visit cue explicitly invites one safe experiment: choose an intent and watch the structure change.
4. Explicit intent changes use a short one-time structural settle animation; passive page load never uses that choreography as spectacle.
5. Explore/Lab/Evidence receive a compact continuing-context ribbon when there is meaningful local context.
6. The Page Guide launcher is renamed **Adapt this page** to make agency discoverable.

## Boundary
This layer explains adaptation. It does not change product truth, evidence, telemetry, public maturity or semantic history.
