# Guided Path Contract — v1.9

- Start only after explicit activation of `#trace-journey`.
- Maximum three product-world steps.
- Every step must follow the versioned connection graph.
- Automatic steps use `source="journey"` and must not be persisted as deliberate selections.
- A deliberate click, swipe or related-world action cancels the running journey immediately.
- Reduced-motion/low-power modes shorten state changes and suppress nonessential transitions.
- The journey changes presentation only; it cannot alter product maturity, evidence or semantic history.
