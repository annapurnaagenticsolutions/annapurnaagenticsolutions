# Real-State Current Contract

The Living World may translate verified public repository state into ambient motion, provided the translation remains low-stakes and truthful.

## Source
`data/repository-signals.json`

## Allowed effects
- packet velocity;
- connection density/opacity;
- subtle route-current animation state.

## Prohibited interpretations
Repository commits, issues, stars, or forks must not:
- imply users/customers/adoption;
- upgrade product maturity;
- generate semantic-history milestones on their own;
- alter evidence statements;
- appear as a marketing performance claim.

The Home page intentionally visualizes activity rather than showing a repository dashboard. Exact metrics remain available on the Evidence page.
