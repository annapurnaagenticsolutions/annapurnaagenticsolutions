# Public Link Contract v4.2

- Every externally presented engineering source URL is HTTPS.
- GitHub source links remain inside the `annapurnaagenticsolutions` public namespace.
- Every `target="_blank"` link carries `rel="noopener noreferrer"`.
- Public Pages and source-code destinations are visually distinguished as **Live/Pages** versus **Source** where both exist.
- The Contact page does not simulate submission or success without a backend.
- Public maturity statements remain governed by Evidence; a link existing does not imply production readiness.
- `data/public-links.json` is the canonical release registry for company/public destinations introduced in v4.2.
