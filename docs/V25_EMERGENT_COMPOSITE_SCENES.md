# v2.5 — Emergent Composite Scenes

## Objective
Let causal interaction across multiple product worlds create a temporary seventh state that belongs to the combination, not to any single product.

## Unlock rule
A composite requires an inherited causal chain, not only a click sequence:
1. complete world A;
2. enter connected world B and absorb A's incoming consequence;
3. complete B;
4. enter connected world C and absorb B's incoming consequence;
5. complete C.

Only then can the matching composite emerge.

## Four combinations
- **AI → AXON → Software Lab** → **Governed Runtime**
- **WonderHub → Website Studio → AI** → **Adaptive Experience**
- **Idea Hub → Software Lab → AXON** → **Prototype → System**
- **Website Studio → WonderHub → Idea Hub** → **Experience → Action**

## Emergent behavior
When unlocked, unrelated worlds recede; the three member worlds converge; the canvas closes a three-edge current; the semantic scene word and core role change; and the Connected Journey recomposes around the emergent combination. Any deliberate new world selection releases the composite.

## Boundary
The composition is an experiential representation of portfolio relationships. It does not claim that live products invoked one another. State exists only in page memory and clears on reload.
