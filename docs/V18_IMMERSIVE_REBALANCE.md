# v1.8 — Immersive Rebalance

## Problem
v1.6/v1.7 improved first-visit clarity but over-corrected: more of the intelligence was described in copy while the atmosphere/spatial character became quieter. The site started teaching the “living website” concept instead of simply feeling alive.

## Rebalance
- Preserve white background, professional typography and four-page information architecture.
- Restore spatial depth to the Home ecosystem rather than adding more landing-page sections.
- Make each product world visually distinct while using the same semantic six-world model.
- Couple motion to pointer, scroll, product choice, public state or deliberate visitor action.
- Replace the explanatory “Why living” section with an actual connected product route.
- Keep adaptation and Page Guide capability, but remove implementation-method copy from visible surfaces.

## Six visual physics
1. AI Solutions — governed network.
2. WonderHub — learning constellation.
3. Idea Hub — practical city blocks.
4. AXON — typed workflow lanes.
5. Website Studio — responsive experience frames.
6. Software Lab — experimental grid.

## What remains deliberately excluded
- custom cursors;
- cursor trails;
- magnetic buttons;
- confetti;
- autoplay audio;
- parallax on every element;
- decorative 3D without product meaning.

## 3D decision
Three.js/WebGPU remains optional. v1.8 first proves that a dependency-free Canvas/CSS scene can deliver meaningful spatiality and causal interaction on the professional baseline.
