# v1.9 — Immersive Coherence

## Problem observed after v1.8
v1.8 restored atmosphere, but some of the hero still behaved like a sophisticated control panel: world selection changed the node and environment, yet the whole page did not always feel as if it had moved into that world.

## Changes
1. World selection now reframes the full stage with world-specific x/y/tilt, background and global accent.
2. A large low-opacity scene verb creates a visual anchor without adding copy density.
3. Internal adaptive receipts and phase labels are hidden from visitors.
4. Guided product paths are explicit user actions, not autoplay.
5. Guided steps are non-persistent; deliberate user selection interrupts the guide immediately.
6. Explore cards preview the same world grammar used by the hero.
7. Active-world accent continues subtly into capability, route and CTA surfaces.
8. No new runtime framework or WebGL context was introduced.

## Design rule
Experience first. Product meaning drives motion. Visitor-facing pages never explain the implementation philosophy.
