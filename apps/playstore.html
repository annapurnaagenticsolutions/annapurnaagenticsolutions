🔒 ZERO PII COLLECTED

Why CareLink Play Store?

🔐

Privacy-First Design

No personal data collection. No device fingerprinting. No telemetry. By design, there's nothing to leak or breach.

✈️

Offline-First

License verification works in airplane mode. Apps function fully offline. Only license issuance requires internet.

🔑

Cryptographic Licensing

Ed25519 signatures + RSA-OAEP encryption. Device-bound keys in Android Keystore. No server-side decryption possible.

⚡

Edge-Deployed

Built on Cloudflare Workers. Globally distributed. Sub-100ms response times. Serverless scalability.

🌐

GDPR/CCPA Exempt

No personal data processing = no compliance obligations. Legally inert by design.

🇮🇳

India-Focused

Hindi voice support. Family-oriented apps. Designed for Indian users and use cases.

Backend

  • Cloudflare Workers
  • Hono Framework
